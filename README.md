# prog-web-tareas-2026

Este repositorio ha sido creado exclusivamente para almacenar, organizar y entregar las actividades prácticas y tareas escolares asignadas por el profesor a lo largo del curso de Programación Web. 

## Contenido del repositorio:
* **Estructura modular:** Cada proyecto, práctica o tarea se encuentra organizada en su propia carpeta para facilitar su revisión.
* **Proyecto Actual (Agenda de Contactos):** Aplicación académica que demuestra el consumo de servicios web utilizando un frontend reactivo en Angular (Signals) y un backend en FastAPI.
* **Futuras entregas:** Espacio preparado para añadir los siguientes ejercicios de la materia de forma limpia y ordenada.

*Nota: Este espacio es de carácter puramente académico y didáctico para el seguimiento de la asignatura.*
